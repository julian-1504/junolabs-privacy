# VocTrainr

Ein Vokabeltrainer für Android. Die Vokabelseite aus dem Schulbuch fotografieren, mit dem
Karteikasten lernen, eine Lernserie aufbauen. Kein Konto, keine Werbung, kein Server — alles
bleibt auf dem Gerät.
